# 架构决策记录（ADR）

记录「为什么这么做」——代码本身能说明「做了什么」，但说不清被否决的方案与
当时的约束。这些决策在新人接手或想改动时最需要。

格式：每条记录包含**背景 / 决策 / 理由 / 影响**。编号不复用，推翻旧决策时
新开一条并在旧条目顶部标注「已被 ADR-XXX 取代」。
