# Data and Privacy

> [← Back to documentation index](../../../README_EN.md#docs)

**Local-first, and the data is yours.** The app has no account system, no telemetry, and no built-in providers — every byte of data lives on your own disk.

## Where all the data lives

```
~/.lyclaw/
├── data.db              # Sessions, messages, settings (including keys) — SQLite, the core of everything
├── skills/              # Skill library
├── scheduled_tasks.json # Scheduled tasks
├── skill_market.json    # Skill market cache
└── data/
    ├── remote.json      # Phone remote pairing code (generated by the server)
    ├── memories.json    # Long-term memory
    ├── mcp.json         # MCP server configuration
    ├── screenshots/     # Computer Use / screenshot tool artifacts
    └── sessions.json    # Legacy session archive (kept read-only)
```

> The data directory used by older versions, `~/.laoyou-agent/`, is **migrated automatically** into `~/.lyclaw/` when the new version starts — nothing to do by hand.

## What leaves this computer

Only two kinds of traffic, both triggered by you:

1. The **model provider** you configure: chat content and tool results are sent to it (this is inherent to the AI features)
2. The **web access** you request: fetching and searching the URLs you specify

The app itself: zero telemetry, zero analytics, zero built-in services.

## Key protection

- Keys are stored in local SQLite; anything echoed back in the UI is masked (`sk-6****9Ylc`)
- Masked values are **never written back** to storage — saving the whole settings form cannot overwrite a real key with its mask
- Cross-site protection: malicious web pages cannot read local APIs through your browser (same-host gatekeeper 403 + DNS-rebinding 421)

See [SECURITY.md](../../../SECURITY.md) (中文) at the repository root for details.

## Backup and restore

**Settings → Backup (设置 → 备份)**:

- **Export (导出)**: downloads a complete JSON (sessions + messages + settings + memory). The file **contains plaintext keys** — that is exactly its purpose, full restoration — so guard it like a password-manager export
- **Import (导入)**: pick a backup file to restore from; masked values are skipped automatically and never pollute your existing configuration

## Complete removal

```bash
rm -rf ~/.lyclaw
```

Deleting that one directory wipes sessions, keys, memory, skills, and the pairing code — no trace left behind.
