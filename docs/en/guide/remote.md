# Phone Remote

> [← Back to documentation index](../../../README_EN.md#docs)

Put the entire workstation in your pocket: chat from your phone, the computer does the work, and progress streams back to your phone in real time.

## Setup

1. On the desktop: **Settings → Remote Access (设置 → 远程访问)** — once the QR code appears, you are ready
2. On the phone: scan the code while on the same LAN, or open `http://<desktop-ip>:3211/remote.html?t=<pairing-code>` in a browser
3. The page pairs automatically — no app to install

## Capabilities

| Capability | Description |
|---|---|
| Chat | Full Markdown rendering and code highlighting, identical to the desktop app |
| Tool calls | All 51 tools plus MCP — anything the desktop can do, it can do |
| Ask with a screenshot | Send a screenshot to the model and it answers by reading the image |
| Sub-agent progress | Parallel sub-agents dispatched on the computer, with progress cards synced in real time |
| Notifications | Task completions are pushed into the phone's message stream |

## Security model

Remote access ships **with the door closed**:

- Requests from other machines must carry a **pairing code** (the `t=` parameter in the URL or a request header), otherwise the API returns 401 across the board
- Without a pairing code, even the page itself is out of reach (404) — a stranger on the LAN cannot detect that the entry point exists
- The pairing code is generated by the desktop; **Re-pair (重新配对)** invalidates the old code immediately
- Cross-site protection is active at all times: malicious web pages cannot reach these APIs through your browser

> Phone remote is a **LAN trust model**: a device holding the pairing code counts as the owner. Do not enable remote access on untrusted networks such as coffee-shop Wi-Fi; the app intentionally provides no public tunnel.

## FAQ

**Can't open the page on the phone?**
Make sure the phone and the computer are on the same Wi-Fi; make sure the QR code is still showing on the desktop (the service is running); allow port 3211 through the firewall.

**"配对码无效 (invalid pairing code)" after scanning?**
**Re-pair (重新配对)** was clicked on the desktop, so the old code is already void — just scan again.

**Is this the same session as the desktop?**
Yes. What you see remotely is exactly the desktop's data, and disconnecting and reconnecting on the same phone loses no context.
