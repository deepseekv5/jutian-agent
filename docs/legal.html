用户协议

欢迎使用巨天agent。请在使用前阅读并理解本协议。安装、使用本软件即表示你已阅读并同意本协议的全部内容。本软件为本地部署的开源软件（MIT 许可证），主要在用户自己的计算机上运行。

一、服务性质与运行方式

  • 本软件是一个桌面端人工智能工作台，提供对话、编码辅助、AI 角色、知识库、定时任务等功能。
  • 人工智能输出内容由你自行配置的模型服务生成（自备 API 密钥，或使用第三方免费网关）。巨天agent 作为客户端软件转发你的请求并展示结果，不控制模型服务的具体输出。
  • 本软件在本地计算机上运行与存储。将软件用于向第三方提供服务的，由使用方自行承担服务提供者义务。

二、AI 生成内容与标识

  • 本软件对 AI 生成内容添加显式标识（如「AI 生成」角标、导出文件内嵌标识声明）。依据《人工智能生成合成内容标识办法》及《互联网信息服务深度合成管理规定》，你不得删除、篡改或隐匿上述标识。
  • AI 生成内容可能存在错误、虚构或偏差，不构成任何专业建议。重要决策请自行核实或咨询专业人士。
  • AI 角色等拟人化互动功能为虚构人设：角色不对应任何真实个人，不得用于冒充他人。你正在与 AI 而非真人互动的提示将全程展示。

三、用户行为规范

  • 不得利用本软件生成、传播法律法规禁止的内容，包括但不限于：危害国家安全、暴力恐怖、淫秽色情、侵犯他人名誉权/肖像权/隐私权/知识产权的内容。
  • 不得利用 AI 角色功能对未成年人提供虚拟亲属、虚拟伴侣等虚拟亲密关系服务，不得诱导未成年人沉迷。
  • 不得利用本软件实施诈骗、骚扰、虚假信息传播或其他违法违规活动。
  • 使用第三方模型服务时，还应遵守该服务商的服务条款。

四、未成年人保护

  • 不满十四周岁的未成年人使用本软件涉及个人信息处理的，应当取得其父母或其他监护人的同意。
  • 本软件不向未成年人提供虚拟亲属、虚拟伴侣等虚拟亲密关系服务。
  • 监护人应当引导未成年人合理使用人工智能工具，防范过度依赖。

五、知识产权

  • 本软件依据 MIT 许可证开源发布。软件本身的著作权与许可条款见仓库 LICENSE 文件。
  • 你输入的内容的权利归属由你与相关权利人依法确定。AI 生成内容的使用与商用权利，还受你所用模型服务商条款约束，请自行查阅。
  • 「巨天agent」名称与标识归巨天工作室所有。

六、责任限制

  • 本软件按「现状」提供。在法律允许的最大范围内，开发者对因使用或无法使用本软件造成的间接损失不承担责任。
  • 本条不限制依法不得免除或限制的责任，也不免除本软件依法应承担的内容管理、标识、个人信息保护等法定义务。
  • 因违反本协议使用本软件（包括用于违法违规用途）造成的后果，由使用者自行承担。

七、自动更新与镜像通道

  • 本软件默认启用自动更新：启动后与使用过程中会自动检查新版本，发现后自动下载并完成校验与替换。更新过程不会自动重启，完成后将提示你「重启即用」，重启后生效。
  • 更新检查与下载默认访问 GitHub（api.github.com 与 release 资产地址）。当网络无法连通 GitHub 时，会自动依次切换第三方镜像站完成同样操作；镜像站由公开社区运营，可能收到你的 IP 地址、请求时间与下载内容，其隐私与可用性由相应运营方负责。
  • 你可以在设置中手动检查更新；卸载或删除本软件不影响已完成更新的运行。

八、协议的变更与终止

  • 本协议可能随软件版本更新而修订，重大变更将通过应用内公告提示。
  • 你可以随时停止使用并卸载本软件；卸载前可使用应用内的数据导出与删除功能处理你的数据。
  • 本协议适用中华人民共和国法律。

隐私政策

巨天agent 以本地优先为设计原则。本政策说明本软件处理哪些信息、如何处理、存放在哪里，以及你对自己的信息有哪些控制权。个人信息处理者为你自己（数据全部存储于你的计算机），开发者无法访问你的数据。

一、我们处理的信息（全部存于本机 ~/.lyclaw 目录）

  • 对话记录：你发送的消息与 AI 的回复，含工具调用记录。
  • 长期记忆：主对话记忆与你为 AI 角色创建的记忆条目（自定义键值）。
  • 角色数据：你创建/编辑的 AI 角色设定、会话记录。
  • 配置信息：API 地址与密钥、模型选择、界面偏好、工作目录。
  • 知识库：你主动导入的文档与索引。
  • 统计数据：本机的调用次数与 token 估算（不包含消息内容）。

二、信息的使用与不对外提供

  • 上述信息仅存储在你的计算机上，用于向你提供软件功能。开发者不收集、不上传、无法访问这些数据。
  • 你的聊天内容不会用于训练任何模型。
  • 当你使用在线模型服务时，实现当前对话功能所必需的内容（对话文本、附件）会发送给你所配置的模型服务商，并受其隐私政策约束——请在配置前阅读服务商的条款。
  • 使用免 key 免费网关（如 Kilo、Pollinations）时，对话内容同样会经过该第三方网关，请知悉。

三、自动更新产生的网络通信

  • 自动更新时，软件会访问 GitHub 获取版本信息（可能包含：IP 地址、软件版本号、系统平台）。更新包内容为程序代码，不含你的个人数据。
  • 当 GitHub 不可达时，将依次尝试第三方镜像站；该过程同样会发生上述网络通信。
  • 你可以选择不更新继续使用旧版本，但可能无法获得安全修复与新功能。

四、敏感场景提示

  • 对话中主动提供的健康、财务、身份等信息属于敏感个人信息，是否提供由你决定。建议避免在对话中输入不必要的敏感信息。
  • AI 角色的长期记忆是你明示创建或确认的，可随时查看与删除。

五、你的权利（查阅 / 复制 / 更正 / 删除）

  • 查阅与复制：记忆页（含角色记忆分区）可查看全部记忆；对话记录、知识库在对应页面均可导出。
  • 更正与删除：任何一条记忆、一个角色的会话与记忆、整段对话均可一键删除，删除后不可恢复。
  • 一键清除：卸载前删除 ~/.lyclaw 目录即可完全清除本软件产生的全部数据。
  • 撤回同意：关闭相关功能（如角色记忆、自动朗读）即停止对应处理。

六、安全措施

  • 数据仅写入本机用户目录；远程访问（WebUI）默认关闭，开启后仅限局域网并使用配对令牌。
  • API 密钥存储于本机，界面回显为掩码，不会随对话内容发送给第三方。
  • 本软件为开源软件，数据读写逻辑可公开审计。

七、未成年人信息

  • 不满十四周岁未成年人的个人信息属于敏感个人信息。监护人为未成年人配置使用前，请知悉本政策全部内容。
  • 本软件不主动收集年龄信息；未成年人模式下将限制相关功能。

八、政策更新

  • 本政策随软件功能更新而修订（如新增需要说明的数据处理场景），版本与更新日期将在文档顶部标注。
  • 重大变更将通过应用内公告提示。
