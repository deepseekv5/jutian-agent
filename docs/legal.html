二、功能范围

  • 知识库与记忆：将文件夹与笔记导入知识库并建立索引与关联；跨会话长期记忆的管理（查看、修改、删除）。

  • 语音：语音通话模式、文本朗读（支持多平台语音合成与多音色语速）、语音输入（浏览器识别或云端识别）。
  • 自动化：定时任务（按计划自动执行提示与任务）、待办清单、目标模式（自动评估任务完成度并续跑）。
  • 演示文稿：AI 生成与编辑 PPT，支持导出。
  • 文件空间：默认工作区自动创建于数据目录下的 workspace（桌面 ~/.lyclaw/workspace；手机端在应用数据目录内），AI 的文件产出默认落在这里，可在应用内浏览与编辑。

  • 开放接口：本机开放 OpenAI 兼容 API 与 jtcode 命令行工具，供其他本地程序调用（默认关闭，开启后仅限本机）。

三、服务性质与运行方式

隐私政策

巨天agent 以本地优先为设计原则：业务数据全部存储在你的设备上，开发者不收集、不上传、无法访问你的数据。本政策逐项说明本软件处理哪些信息、如何处理、存放在哪里、什么情况下会经第三方，以及你对这些信息有哪些控制权。个人信息处理者为你自己（数据全部存储于你的设备）。

一、总原则：零遥测

  • 本软件不内置任何遥测、埋点或崩溃上报。你的使用行为不会被统计或发送给开发者。
  • 开发者无法远程访问你的设备与数据；不存在开发者侧的服务器存储你的业务数据。
  • 本软件为开源软件，全部数据处理逻辑可公开审计。

二、存储在你设备上的信息（本地数据清单）

  • 对话记录：你发送的消息与 AI 的回复，含工具调用记录与消息分支。
  • 长期记忆：主对话记忆与你为 AI 角色创建的记忆条目（自定义键值，可在记忆页查看与删除）。
  • 角色数据：你创建/编辑的 AI 角色设定与会话记录。
  • 配置信息：API 地址与密钥、模型选择、权限档位、界面偏好、工作目录、界面语言等。
  • 知识库：你主动导入的文档、笔记与向量索引。
  • 文件空间：默认工作区（桌面 ~/.lyclaw/workspace；手机端在应用私有数据目录内）中的全部文件——包括 AI 生成的文件。
  • 技能：你从技能市场安装的技能文件（存于数据目录 skills 下）。
  • 统计数据：本机的调用次数与 token 估算（不含消息内容）。
  • 日志与缓存：诊断报告、语音合成缓存、更新下载缓存（均在本机，可随时删除）。
  • 存储位置：桌面端 ~/.lyclaw 目录（SQLite 与 JSON 文件）；安卓本地版在应用私有数据目录（系统设置里显示为「巨天agent」的应用数据）。

三、信息的对外传输（仅在你使用对应功能时发生）

  • 模型服务：使用在线模型时，实现当前对话所必需的内容（对话文本、思考内容、附件、工具结果）会发送给你配置的模型服务商，并受其隐私政策约束——请在配置前阅读服务商条款。对话内容不会用于训练任何模型（是否用于训练取决于服务商条款）。
  • 免费网关：使用免 key 免费网关（如 Kilo、Pollinations）时，对话内容同样经过该第三方，请知悉其免费服务的性质与限制。
  • 联网搜索：深度调研与联网搜索工具会把检索词发送给公共搜索引擎与聚合服务（Bing、DuckDuckGo、SearXNG 公共实例等）。
  • 技能市场：浏览与安装技能时，软件会访问 GitHub 公开仓库与相关 API；安装的技能文件来自你选择的来源仓库，其内容与安全性由来源作者负责。
  • 自动更新：检查与下载更新时访问 GitHub（可能涉及 IP 地址、软件版本号、系统平台）；GitHub 不可达时依次尝试第三方镜像站。
  • 语音识别：使用浏览器语音识别时不经过本软件的服务端；使用云端识别时，音频会上传给你配置的模型服务商的识别接口。

八、敏感场景提示
