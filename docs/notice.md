# 巨天 Agent 版本更新要点

* **v14.15.0**：主界面整装 + 新手引导 + 应用内文档 + 后端提速。输入框主行只留「+ 联网 公文 思考 模型」，目标/调研/计划/权限收进 + 菜单「会话控制」区；顶栏去冗余版本号；侧栏功能图标弹性均分防重叠。首次启动出现聚光灯式新手引导（5 步过关键入口，关于页可重看）；新增「使用文档」页（侧栏书本图标）：内置 8 篇离线指南（快速上手/模式与权限/公文写作/巨天安全/终端版/快捷键/数据隐私/FAQ）。后端 settings 读取加微缓存（安全盾等热路径每工具调用 3 次读库收敛为 1 次，写即失效）。
* **v14.14.0**：新增「党政红」主题与公文模式。主题：宣纸暖底 + 红金配色 + 标题宋体（GB/T 9704 风格），强调色新增党政红；公文模式：输入框「公文」开关（或 /公文 命令），AI 按党政机关公文规范产出——文种识别、主送机关、结构层次序号（一、（一）1.（1））、规范惯用语与落款成文日期。
* **v14.13.2**：修复 CPU 占用过高。扩展同步自激循环（约 550 次/秒打本地服务，主进程 130% 空转自 v14.11 起），已改为注册表真正变化时才广播。
* **v14.13.1**：终端版升级。支持工作目录请求级隔离、会话落盘、忙时输入自动排队、思考内容流式显示、Markdown 渲染与提示音；新增 `/model` 切换模型及中英双语文档。
* **v14.13.0**：终端版 `jtcode` 全面重做。对齐桌面端 Agent 循环与安全门禁；引入 ink 版终端 UI，支持自动拉起后端；修复上游参数丢失问题。
* **v14.12.0**：上线「巨天安全」功能。提供危险命令拦截、提示词注入扫描及密钥屏蔽与占位符替换三道防线，支持安全记录查看与防护库更新。
* **v14.11.5**：UI 流畅度专项优化。移除重复的玻璃材质模糊开销，优化侧栏动画、自动滚动、录音波形帧率及多标签页性能。
* **v14.11.3**：新增 GitHub Star 引导。首次启动及免费模型页增加求星提示。
* **v14.11.2**：新增本地 API 实时活动动画与服务端双写日志，并修复本地知识库落盘及原生模块自检问题。
* **v14.11.1**：Agent 内核新增 Harness 选项，支持在设置中嵌入 the agent harness WebUI 面板。
* **v14.11.0**：上线用户扩展层（UXL）。支持 AI 通过 `create_extension` 工具创建、沙箱运行并管理自定义界面面板。
