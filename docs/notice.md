v13.5.0：多端适配与英文界面。手机/平板完整适配——侧栏改抽屉、新增底部导航、输入区随软键盘抬升、刘海屏安全区适配、弹窗全屏、触摸目标加大；首次启动跟随系统语言，界面英文覆盖大幅补齐（命令面板/技能市场/侧栏/关于页/空状态全量双语，集中式 203 键字典保证中英同步）；新增断网提示与"添加到主屏幕"安装引导。共 50 项变更，清单见 docs/guide/ui-i18n.md。

v13.4.1：桌面更新包体积修正——依赖分层归位后 app.asar 从 125MB 回落到 14.5MB，自更新不再多下 100MB。功能与 13.4.0 一致。

v13.4.0：安卓双版本。本地版（jutian-local-*.apk）内置 Node 运行时与完整前端，装一个 APK 就能在手机上跑完整 Agent，不需要电脑也不需要 Termux；远控版（jutian-remote-*.apk）保持轻量连电脑。

v13.4.0：安卓分为两个版本。**本地版**（jutian-local-*.apk，约 40MB）内置 Node 运行时与完整前端，装一个 APK 就能在手机上跑完整 Agent——工具、技能市场、对话、记忆全在，数据存手机本地，不需要电脑也不需要 Termux。**远控版**（jutian-remote-*.apk，约 60KB）保持轻量，连电脑或 Termux。两者同签名可互相覆盖安装。

v13.3.0：多端能力打通。数据存储三档自适应——桌面用原生 SQLite，手机（Termux）自动改用 Node 22+ 内置 SQLite，同样是真 SQL（知识库可用），老版本 Node 才退 JSON 存储。语音全平台可用：Edge TTS 失败时自动改用系统语音（macOS 朗读 / Windows SAPI / Linux espeak），实测微软 403 也能出声；语音输入在本地识别不可用时走云端识别。安卓端新增双模式引导页（本机运行 / 连接电脑）并显示版本号；Windows 安装包恢复发布（修复发布门禁的代码检查错误）。手机独立包体积约 6MB，含语音引擎。

v13.2.0：性能与体验底盘——长会话渲染虚拟化（千条消息的会话滚动与流式输出不再随历史长度变卡，浏览器自动跳过视口外内容的渲染）；手机浏览器「添加到主屏幕」支持（PWA 清单+图标，桌面级全屏体验）；诊断接口升级（运行时长/内存/存储引擎/Node 版本一个请求看全）；按钮无障碍标签补全。

v13.1.0：聊天渲染全面升级——Mermaid 图表自动渲染（流程图/时序图/甘特图，图与源码一键切换）、数学公式排版（KaTeX，支持 $ 与 \( \) 两种写法）、HTML 代码块「预览」页签（Agent 生成的网页直接在对话里打开，沙箱隔离）。以上能力全部按需加载，不用图表和公式的会话零开销。

v13.0.0：技能市场接入真实来源——直接安装 Anthropic 官方技能库（18 万 star 的 anthropics/skills）与 Superpowers 社区技能集，共 30+ 个专业级技能（PDF/PPT 处理、前端设计、品牌规范、MCP 构建等），安装前可预览完整 SKILL.md 说明，一键装进你的 Agent。消息气泡新增「分享图」：把任意一条回答导出成品牌分享卡片 PNG，可直接发朋友圈/微博/群聊。

v12.9.0：手机独立运行——安卓手机装 Termux 即可跑完整 Agent（不依赖电脑），对话数据本地落盘；安卓 APK 启动时自动探测本机服务。

v12.8.0：全平台发行版上线——mac（arm64/x64 dmg+zip）、Windows 安装包、Linux（AppImage/deb/tar.gz，x64+arm64）全部由 GitHub 构建服务器自动出品，打 tag 即发版。

v12.7.1：安卓安装包已改由 GitHub 官方构建服务器自动构建（打 tag 即出包，签名与历史版本一致，覆盖安装无损）。

- 知识库搜索加向量缓存（重复搜索不再重复解析全表）

v12.6.0（全码审计·安全加固）：

- 修复语音服务子进程管道阻塞（TTS 用一阵子失声的根因）
