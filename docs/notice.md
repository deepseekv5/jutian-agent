v12.8.0：全平台发行版上线——mac（arm64/x64 dmg+zip）、Windows 安装包、Linux（AppImage/deb/tar.gz，x64+arm64）全部由 GitHub 构建服务器自动出品，打 tag 即发版。

v12.7.1：安卓安装包已改由 GitHub 官方构建服务器自动构建（打 tag 即出包，签名与历史版本一致，覆盖安装无损）。

v12.7.0（性能优化）：

- 首屏 JS 体积减 37%（CodeMirror 编辑器改为按需加载）
- 启动少等 1 秒（去掉固定盲等，改为端口探测）
- 知识库搜索加向量缓存（重复搜索不再重复解析全表）

v12.6.0（全码审计·安全加固）：

- 修复更新包无完整性校验的供应链风险（现在校验官方 SHA-256）
- 修复 Markdown 预览的 javascript: 链接注入（XSS）
- 内嵌浏览器与应用会话隔离（凭据不进外部页面）
- 修复语音服务子进程管道阻塞（TTS 用一阵子失声的根因）

v12.5.0：

- 新增「多模型对比」：同一问题并行发给两个模型并排看回答，选模型不用再猜
- 新增「待办清单」：AI 在对话中维护的工作步骤现在看得见了（三列看板）
- 模型推荐显示真实成功率（按你的实际使用统计，样本≥3 才显示）
- CI 增加 Windows 矩阵，Windows 专属问题在提交阶段就能拦住
