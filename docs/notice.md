v12.2.1 更新（安全加固）：

- 界面不再能在浏览器里打开——只能在 App 内使用
- 修复：本机其他网页可读取 API Key 的漏洞
- 加固：防止被网页嵌入、补齐安全响应头

v12.1.1 的内容（真实接线 + 新功能）：

**底层重构**
- 网络请求统一收口：超时、重试、错误归类一次到位，不再出现"请求挂死"或把 500 当成功
- 错误提示改成人话：密钥无效 / 限流 / 余额不足 / 上下文超限分别给不同建议
- 本地存储加了降级保护，隐私模式下界面设置也不会崩

**新功能**
- 侧栏会话支持置顶、标签分类、归档，右键即用
- 提示词模板库（10 个常用模板，填参数直接用）
- 代码片段库，输入触发器自动展开
- 用量与成本面板：Token 趋势、按模型花费、预算提醒
- 环境诊断：一键自检并复制报告
- 模型推荐：按任务类型给出建议，带理由
- 断网时消息自动排队，网络恢复后按顺序重发
- 新增 8 个工具：diff 对比、待办清单、正则搜索、目录统计、剪贴板读写、打开路径、zip 打包

装完直接可用，无需重装。
