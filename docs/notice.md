v14.12.0：新功能「巨天安全」（设置 → 安全顶部）——三道防线默认全开：① 危险命令拦截：rm -rf 根目录/递归强删/dd 写裸设备/抹盘/fork 炸弹/关机等毁灭性命令在进入 shell 前直接拦下并说明原因；② 提示词注入扫描：工具输出回给模型前扫描「忽略之前的指令」「你现在是…」等注入话术（中英双语 + 伪对话标记），命中即打标提醒模型勿照做；③ 密钥屏蔽与占位符：工具输出里的真实 key/token 自动打码再回给 AI（sk-/ghp_/Bearer 等通用形态兜底），反向地 AI 可在 shell 命令里用 {{KEY}}/{{BASE}} 占位符引用密钥/地址——执行时才替换，密钥全程不进对话上下文。拦截规则 = 内置毁灭性规则 + 恶意命令库（55 条精选，源自 SigmaHQ/LOLBAS 公开检测规则提炼：反弹 shell/挖矿/LOLBAS/提权/防御破坏/敏感外带/持久化），带只读段抑制（grep 到矿池 URL 不算执行）。设置页显示防护库版本（内置+远程+生效条数），「检查更新」实时拉最新库（Gitee 直连 → GitHub 回落，校验通过才落盘，防回退）。实测 AI 被拦后会换变体重试：关机类已按「执行意图」全位置拦截（bash -c / ssh / systemctl / osascript AppleScript 关机全封）。以上所有事件（拦截/标记/打码/替换）落「安全记录」，设置页可查看、刷新、一键清空（最近 200 条）。29 个新测试用例，全量 966 绿。

v14.11.3：GitHub Star 求星——首次启动会全屏请求给仓库点个 Star（可跳转、可稍后、可永久不再提示）；免费模型页顶部也加了可关闭的 Star 横幅。项目完全免费、本地优先、零遥测，Star 是让更多人发现它、让更新继续下去的最好方式。

v14.11.2：本地 API 实时活动动画——设置 → 本地 API 开启后，外部调用（编辑器插件/脚本/局域网设备）会实时显示在「实时活动」区： siapa在用、用了哪个模型、问了什么（前 80 字，不存全文）、首字延迟与总耗时；回复中时有呼吸绿点脉冲动画与「正在回复」状态。服务端内存+磁盘双写，最近 30 条。另修复知识库在原生模块缺失时被静默丢弃：jsondb 的 kb 方法改为真落盘（条目/分块/笔记本/全文搜索），9 处 HTTP 硬拒绝去掉，嵌入失败仍存分块文本；CI 新增原生模块架构自检（mac/win/linux 打包后断言 .node 存在且架构正确，不合格阻断发布）。

v14.11.1：Agent 内核新增「Harness」选项——设置里选中后可配置 the agent harness 服务地址（默认 127.0.0.1:3080），应用内直接嵌入其 WebUI 面板（独立 partition 隔离）。语义说明：Harness 是独立 Cordis 应用，不提供可嵌入的 npm 内核或 OpenAI 兼容端点，因此巨天只当壳展示，不会替换自身的对话循环；需用户自行 npx @deepseek-ai/dsh web 启动，未启动时有明确指引。零新依赖、与官方更新不冲突。

v14.11.0：用户扩展层（UXL）——AI 可以自己创建界面面板了。对 AI 说「给我做个番茄钟面板」，它会用 create_extension 工具生成 HTML 面板 + manifest 写入 ~/.lyclaw/extensions/；到「扩展」页批准后即可打开使用，可随时禁用/删除。官方更新只替换 app.asar，用户层扩展完整保留，与发版不冲突。扩展运行在无同源权限的 iframe 沙箱中，拿不到密钥/Cookie，只能通过白名单桥读数据；manifest 带 apiVersion，宿主升级不兼容时自动禁用不白屏。设计取向学习 the agent harness Creator Mode（检查运行时→写插件→批准→热挂载→可回滚）。
