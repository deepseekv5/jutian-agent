# 手机远程

> [← 返回文档索引](../../README.md#docs)

把整台工作台装进口袋:手机上发消息,电脑里干活,进度实时回手机。

## 开启

1. 电脑端:**设置 → 远程访问**,二维码出现即已就绪
2. 手机:同一局域网内扫码,浏览器打开 `http://<电脑IP>:3211/remote.html?t=<配对码>`
3. 页面自动配对,无需装任何 App

## 能力清单

| 能力 | 说明 |
|---|---|
| 对话 | Markdown 全渲染、代码高亮,与桌面同源 |
| 工具调用 | 全部 38 工具 + MCP,桌面能干的它都能干 |
| 截图提问 | 发一张截图给模型,它看着图答 |
| 子代理进度 | 电脑上派出的并行子代理,进度卡片实时同步 |
| 通知 | 任务完成推送进手机的消息流 |

## 安全模型

远程访问默认**关着门**:

- 非本机请求必须持**配对码**(URL 里的 `t=` 参数或请求头),否则 API 一律 401
- 不带配对码连页面本身都拿不到(404),局域网里的陌生人感知不到入口的存在
- 配对码由电脑端生成,「重新配对」立即作废旧码
- 跨站防护全程生效:恶意网页无法借你的浏览器碰这些接口

> 手机远程是**局域网信任模型**:拿到配对码的设备等同机主。请勿在咖啡店等不可信网络里开启远程;本应用不提供公网隧道,这是有意的取舍。

## 常见问题

**手机打不开页面?**
确认手机与电脑在同一 Wi-Fi;确认电脑端二维码处于展示状态(服务已启动);防火墙放行 3211 端口。

**扫码后提示「配对码无效」?**
电脑端点过「重新配对」,旧码已作废——重新扫一次即可。

**会话和桌面是同一份吗?**
是。远程看到的就是桌面端的数据,同一部手机上断开重连不丢上下文。
