# Computer Use

> [← 返回文档索引](../../README.md#docs)

让模型直接操作这台电脑:看屏幕、动鼠标、敲键盘、验证结果。

## 工作循环

```
观察 → 决策 → 执行 → 验证 → (循环,直到完成)
```

1. **观察**:截取当前屏幕(缩放至 1600px 供模型分析,900px 供界面预览)
2. **决策**:模型根据目标与截图决定下一个动作(点击坐标 / 输入文本 / 按键 / 滚动 / 拖拽)
3. **执行**:通过系统级自动化执行动作
4. **验证**:再截屏,确认动作产生了预期效果;没达到就修正后重试

## 两种模式

| 模式 | 行为 |
|---|---|
| 自动执行 | 全程自动,适合可逆的批量操作 |
| **逐步确认** | 每个动作先弹出确认卡,你放行才执行——首次跑新流程、涉及删除/发送等不可逆操作时用这个 |

确认卡会显示:准备执行的动作、目标坐标/内容、当前屏幕快照。

## 权限要求

- **macOS**:系统设置 → 隐私与安全性 → 允许应用「屏幕录制」与「辅助功能」权限
- **Windows**:首次使用时允许 UI 自动化相关授权

## 边界与建议

- 它操作的是**真实桌面**——重要窗口提前收好,别开着网银页面让它跑
- 「逐步确认」是你最好的朋友:第一次让它在任何环境动手,都开着
- 截屏只用于当轮决策,不会持续落盘
