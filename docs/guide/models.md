# 模型接入

> [← 返回文档索引](../../README.md#docs)

## 基本配置

**设置 → 推理**,填三项:

| 项 | 说明 |
|---|---|
| API 地址 | 任意 OpenAI 兼容服务,如 `https://api.openai.com/v1`、`https://api.deepseek.com/v1`、本地 Ollama 的 `http://localhost:11434/v1` |
| API 密钥 | 服务商提供的 key;本地服务可留空 |
| 模型 | 手填,或点「拉取模型列表」从 `/v1/models` 直接选 |

点「测试连接」验证;失败时会显示**上游真实状态码与原因**,不是笼统的「连接失败」。

## 兼容性说明

- 走 OpenAI Chat Completions 协议(`POST /v1/chat/completions`,支持 SSE 流式)
- 密钥同时按 `Bearer` 头与裸 key 两种鉴权口径尝试,兼容部分只认裸 key 的网关
- 上游任何非 200(400/401/429/500)都会**原样透传**状态码与错误体,方便排查

## 思考档位

输入框的 `⚡` 按钮选择思考程度:**关闭 / 低 / 中 / 高 / 最大**。

- 档位会注入系统提示,引导模型把「思考预算」花在难题上
- 选择持久化保存,下次启动沿用
- 对支持推理的模型(DeepSeek-R1 类)效果明显;普通模型表现为提示词侧重不同

## 模式开关(单次生效)

输入框下方一排开关,只对**下一条消息**生效,发送后自动复位:

| 开关 | 效果 |
|---|---|
| 规划 | 先产出任务拆解与计划,再动手 |
| 联网 | 允许本轮使用网页搜索 / 网页抓取 |
| 画画 | 允许调用图像生成 |
| 造技能 | 允许把本轮经验沉淀为可复用的 Skill |
| 集群 | 切换为多员工协作模式,可选团队模板(自动 / 写作 / 开发 / 研究) |

## 语音

- 输入:优先用浏览器原生语音识别(离线、零配置),不可用时自动回退服务端 Whisper
- 输出:自动朗读可开关;打包版内置 edge-tts 服务,音色在设置中选择

## 隐私边界

- 密钥只存在本机 `~/.lyclaw/data.db`,任何界面回显都是掩码(`sk-6****9Ylc`)
- 对话内容只发往**你自己配置**的模型服务;应用本身没有遥测、没有内置服务商
