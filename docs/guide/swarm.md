# 子代理集群

> [← 返回文档索引](../../README.md#docs)

巨天agent 的多智能体能力分两种形态:**集群指挥室**(持久的数字员工团队)和**子代理并行池**(主对话按需派出的临时工人)。

## 集群指挥室

**集群**标签页里,你可以:

- 创建自定义员工(名字、职责、系统提示),也可以直接用内置的「产品 / 开发 / 测试 / 交付」团队
- 员工之间可以 **@** 接力:开发做完 @测试,测试验完 @交付
- 拉**群聊**:多个员工 + 你在同一会话,各自发言
- 指定**老板**:群里的最终交付由谁拍板

团队模板开箱即用:**自动**(模型自己排兵布阵)/ **写作** / **开发** / **研究**。

## 子代理并行池

主对话的模型在任务合适时可调用 `dispatch_subagents` 工具,自行派出 **1–5 个子代理**,每个都拥有完整工具能力(终端、文件、网络……)。

```
  派出 ──▶ ┌─ 调研员 ──▶ 收集资料,输出 notes
           ├─ 开发   ──▶ 实现 + 自测
           └─ 审校   ──▶ 汇总交付
```

- **并行执行**:worker 池并发 3,先完成先收工
- **实时进度**:侧栏 SubAgentTracker 显示每个子代理的阶段与产出,手机远程同步显示进度卡片
- **随时可停**:中止主任务会同时取消在途子代理,已完成的产出保留
- **结果回喂**:全部子代理的产出汇总后交回主对话,由它整合交付

## 什么时候用哪个

| 场景 | 推荐 |
|---|---|
| 一个任务可拆成互不依赖的几块 | 子代理并行池 |
| 长期协作的固定分工(如「写手 + 审校」) | 集群员工 |
| 需要「验收人」角色 | 集群群聊 + 指定老板 |
| 人在外面,想让电脑开干 | 手机远程发任务,进度同步回来 |

## 通知

集群完成、子代理批次结束、定时任务触发,统一进入**通知中心**(铃铛图标),不打断当前工作。
