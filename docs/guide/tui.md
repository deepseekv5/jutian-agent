# 终端版（TUI）

**简体中文** | [English](../../guide/tui.md)

> [← 返回文档索引](../../../README.md#docs)

在终端里直接与巨天对话——Claude Code 式。同一套 51 工具、巨天安全门禁、权限确认，会话与桌面端互通。

## 两个入口

| 入口 | 安装方式 | 说明 |
|---|---|---|
| `jtcode` | 桌面 App 一键安装（设置 → 关于） | 单文件、零依赖 |
| `npm run tui` | 仓库目录内运行 | ink 富界面（工具卡/Markdown），`npm link` 后全局 `jt` |

## 关键语义

- **工作目录 = 启动时所在的文件夹**。在哪个项目目录里启动，就在哪个目录里干活——文件落在那里、命令在那里执行，桌面端自己的工作区不受影响。
- **冷启动**：巨天未运行时自动拉起（已安装的桌面 App，或仓库 `serve.cjs`），就绪后自动进入。
- **权限确认**：写入/删除/敏感操作会问 `[y] 允许 · [n] 拒绝 · [a] 本会话始终允许`——与桌面端同一门禁。
- **会话落盘**：对话保存后桌面端会话列表同样可见。

## 命令

| 命令 | 作用 |
|---|---|
| `/new` | 新对话 |
| `/resume [序号]` | 列出/恢复最近会话（TUI） |
| `/model [序号]` | 查看/切换模型 |
| `/tools` | 查看 51 个工具 |
| `/security` | 查看巨天安全三开关 |
| `/pack` | 更新恶意命令库 |
| `/status` | 后端版本/模型/工作区 |
| `/exit` | 退出 |

## 小技巧

- Agent 忙的时候可以继续输入——消息自动排队，完成后按序发送。
- `Esc`（TUI）中断当前输出；`Ctrl+C` 中断，再按一次退出。
- shell 命令里可用 `{{KEY}}` / `{{BASE}}` 占位符引用已配置的密钥/地址——执行时才替换为真实值，永不回显。
