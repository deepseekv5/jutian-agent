# 数据与隐私

> [← 返回文档索引](../../README.md#docs)

**本地优先,数据归你。**应用没有账号体系、没有遥测、没有内置服务商——所有数据都在你自己的硬盘上。

## 全部数据在哪

```
~/.lyclaw/
├── data.db              # 会话、消息、设置(含密钥)——SQLite,一切的核心
├── skills/              # 技能库
├── scheduled_tasks.json # 定时任务
├── skill_market.json    # 技能市场缓存
└── data/
    ├── remote.json      # 手机远程配对码(服务端生成)
    ├── memories.json    # 长期记忆
    ├── mcp.json         # MCP 服务配置
    ├── screenshots/     # Computer Use / 截图工具产物
    └── sessions.json    # 旧版会话存档(只读保留)
```

> 历史版本的数据目录 `~/.laoyou-agent/` 会在新版本启动时**自动迁移**进 `~/.lyclaw/`,无需手动处理。

## 什么会离开这台电脑

只有两类,都由你主动触发:

1. 你配置的**模型服务**:对话内容与工具结果发给它(这是 AI 功能的本体)
2. 你要求的**网页访问**:抓取、搜索指定的 URL

应用本身:零遥测、零统计、零内置服务。

## 密钥保护

- 存储在本机 SQLite;任何界面回显都是掩码(`sk-6****9Ylc`)
- 掩码值**写不回**存储——界面整表保存不会把真密钥冲成掩码
- 跨站防护:恶意网页无法通过你的浏览器读取本机接口(同宿主门卫 403 + DNS-rebinding 421)

详见仓库根目录 [SECURITY.md](../../SECURITY.md)。

## 备份与恢复

**设置 → 备份**:

- **导出**:下载完整 JSON(会话 + 消息 + 设置 + 记忆)。文件**包含明文密钥**——它就是用来完整还原的,请像对待密码管理器导出文件一样保管
- **导入**:选择备份文件恢复;掩码值会被自动跳过,不会污染现有配置

## 彻底删除

```bash
rm -rf ~/.lyclaw
```

删掉这一个目录 = 会话、密钥、记忆、技能、配对码全部消失,不剩任何痕迹。
