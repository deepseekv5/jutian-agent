# 知识库与记忆

> [← 返回文档索引](../../README.md#docs)

两套互补的机制:**记忆**记偏好与事实(轻、常驻),**知识库**存文档与检索(重、按需)。

## 记忆(remember / recall / forget)

- 模型在对话中自行调用 `remember` 记下值得长期保留的信息(你的技术栈、项目路径、称呼偏好)
- 存的是**索引与摘要**,细节原文按需取回,不撑大上下文
- 你也可以直接说「记住我喜欢用 pnpm」——它会落盘
- 数据在 `~/.lyclaw/data/memories.json`,可随时手改

## 知识库(RAG)

把文档喂给应用,之后的对话可以检索引用:

1. **知识库面板**添加文档(Markdown / 文本)
2. **设置 → 推理**里需要一个 embedding 模型(与对话模型同服务商即可,填好模型名)
3. 会话里打开 **📚 知识库开关**(默认关,避免无关检索),当轮提问即带检索结果

检索链路:问题 → embedding → 相似度召回 → 作为上下文注入 → 模型带引用作答。

## 两者怎么选

| | 记忆 | 知识库 |
|---|---|---|
| 存什么 | 事实、偏好、约定 | 文档、手册、长资料 |
| 大小 | 索引级,几十字一条 | 整篇文档 |
| 触发 | 每轮常驻(轻) | 开关控制,按需检索 |
| 典型用法 | 「记住我用 zsh」 | 导入 API 文档后随便问 |
