- Chrome 无头截图需加 `--no-sandbox --disable-gpu`；不加 `--user-data-dir` 时可能命中缓存导致截到旧页面，用带时间戳的查询参数规避。

**导出能力补齐**（`ppt-export.ts` 整体重写）：
- 主题感知调色板（深合并部分主题），背景按 mode 分别处理（gradient/deep 用深色底 + 低透明度光晕椭圆近似渐变；tint/custom 各自处理）
- **图片真正内嵌**：新增 `svgToPng()`（浏览器 canvas 光栅化）+ `prepareImages()` 预处理，把 `autoIllustration` 产生的 SVG data URI 转成 PNG 后 `addImage` —— 此前图片块只导出 caption、图片被整体丢弃
- **矢量图形 → PPTX 原生形状**：`drawGraphic()` 覆盖 bars/rings/ladder/grid/nodes 等，不再留白
- **原生表格**（`addTable`，含表头配色、斑马纹、列宽）
- **原生图表**（`addChart`：bar/line/pie/doughnut/area/radar，带图例、数据标签、主题色板）
- 列表图标（dot/check/number/dash/none）、步骤页改为序号圆点 + 连接线、页码、演讲者备注

**数据模型扩展**（`types/ppt.ts`）：新增 `TableBlock`、`ChartBlock`（+ `ChartKind`/`ChartSeries`），`LayoutId` 增加 `table`/`chart`/`gallery`，`SlideSpec` 增加 `table`/`chart`/`images`
**版式引擎**（`ppt-layouts.ts`）：新增 table/chart/gallery 的 materialize 与 extractSpec 反向解析
**AI 生成**（`ppt-ai.ts`）：提示词与 sanitize 支持新三种版式（含数值清洗、必需字段校验）
**编辑器**（`PPTView.tsx`）：画布新增表格（原生 table 预览）与图表（轻量 SVG 预览，饼图/环图/柱状）渲染；`PPT_THEMES` 补 `accent2` 双色；导出传入完整主题
