特性与参数

该重的重,该轻的轻。

一个进程,一个窗口,一套完备的工具。下面是没有水分的部分。

系统要求

支持平台
macOS 13 及以上 · Apple Silicon / Intel
Windows 10 及以上 · x64
安装体积
约 120 MB · 首次安装后自动清理临时文件
内存占用
空闲约 380 MB · 低性能设备自动降级玻璃模糊与动画
架构
Electron + Node 单进程 · 界面、引擎、工具服务一体
数据存储
本地 SQLite · 会话、消息、记忆、知识库全部落盘本机
模型接入
自带 API Key · 任意兼容 OpenAI 协议的服务;也可接本地模型
界面语言
中文 / English · 深浅双主题 · 动态壁纸
更新方式
增量补丁 · 只替换变化文件,不重装
完整特性

打开就有的部分。

001

多标签工作区

对话、代码、终端、知识库同窗多开。Cmd+N / T / W 全键盘操作,切走不丢状态。

002

Git 检查点

每轮对话前自动快照工作目录,一整轮改动一键撤销。改坏了不慌。

003

深度思考档位

关闭 / 低 / 中 / 高 / 最大,随消息切换。简单问题不浪费,难问题不糊弄。

004

全局全文搜索

搜标题,也搜每一条消息正文。命中直接跳到那条消息并高亮。

005

玻璃拟态界面

半透明层级加发丝线,浅色深色都干净。低性能设备自动退回纯净底色。

006

语音通话模式

桌面宠物一键唤起,边说边让它干活。开车、走路、双手占用时最好用。

007

命令面板

Cmd+K 唤起,跳会话、开页面、发指令,一步到位。

008

长期记忆

只存索引不塞全文,重要细节按需取。它记得你的偏好与项目上下文。

009

知识库

文档导入即检索,回答有出处。引用可点开,不用猜。

010

截图即问

框选屏幕任意区域,直接问「这是什么」「报错什么意思」。

011

PPT 生成

一句话到可编辑的 .pptx,PowerPoint / Keynote / WPS 直接打开继续改。

012

定时任务

到点自动跑,日报、巡检、监控,它替你盯着。

架构

一个进程,一个入口。

界面层负责对话,Agent 引擎负责决策,37 个工具直连真实系统。请求、决策、执行、回传,闭环在一台电脑上完成。

没有微服务,没有云端编排,没有为了架构而架构。一个窗口把事情办完,是它的全部设计目标。
