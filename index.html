巨天 Agent An agent that actually does the work

一个安装在你电脑里的智能体。它会开终端、改文件、写代码、做 PPT， 也能听你说话再开口回答。不是又一个网页聊天框——它的手是长的， 能碰到你硬盘上真实的东西。

目前还在预览阶段，没有开放下载。这一页可以当说明书看：它现在能做什么、 做不到什么，以及打算怎么往下做，都写在下面了。

一句话区别

常见的 AI 助手止步于"告诉你怎么做"；巨天 Agent 想做的是"替你做完"。 差别看着不大，实际决定了它是个搜索引擎还是个同事。

没发布之前，你也可以先在下面点几下，试试思考档位是怎么回事。

01

它是什么

先说清边界：它能干什么，以及我们不打算让它干什么。

定义

一个装着工具的智能体

巨天 Agent 是一个基于 Electron 的桌面应用。它有一个对话界面， 但对话只是入口——背后接的是一套工具总线：终端、文件系统、代码编辑器、 PPT 生成器、语音识别与合成。你说一句"把这个目录下的日志按日期归档"， 它就会真的去操作这些文件，而不是给你一段需要你自己复制粘贴的命令。

所有数据默认留在本地。对话历史、工作区配置、项目上下文都存在本机的 SQLite 数据库里，不上传服务器，断网也能翻历史记录。 模型方面支持接入多种大模型 API，同时内建 WebLLM 本地推理通道—— 涉及敏感内容的任务可以选择完全不出本机。

它不是一个操作系统级的自动化机器人。它不会在你不知情的情况下 后台运行、修改系统设置或联网抓取数据。每一次文件写入、每一条命令执行， 都会在界面上留下可见的记录。

边界

明确不做的事

  • 01不做后台常驻。关闭窗口即停止一切动作。
  • 02不静默联网。需要访问网络的操作都会在界面明示。
  • 03不收集使用数据。没有埋点，没有遥测，崩溃日志也只存本地。
  • 04不代管你的密钥。API Key 存在本机，由你自己填写和更换。

和普通聊天工具的差别，用具体场景对比一下更直观：

场景普通聊天工具巨天 Agent
要建一个目录结构给你一段 mkdir 命令直接建好，并告诉你建了什么
报错了猜测可能的原因读真实日志再判断，读不出来就说读不出来
要改一百个文件只能逐个贴内容在工作区内批量处理，先行后报
断网时基本不可用本地功能照常，历史记录可翻
数据去哪了在对方服务器留在你本机

可以在你的电脑上执行命令，并把输出实时显示在对话里。装依赖、跑构建、 查日志、起服务——这些原本需要在终端窗口里手敲的事情， 变成一句话的事。

命令执行前会显示完整命令文本，你可以直接看到它准备做什么。 长任务可以中途停止，输出不会被截断丢失。

能读取文件内容、按你的要求改写、批量重命名、按规则归档目录， 也能在大量文件里做内容检索。所有写入都发生在你指定的工作区内， 不会跑到别的地方去。

典型用法：把下载目录里堆积的 PDF 按标题归类、给一批代码文件 批量加注释头、从一堆日志里找出报错时间段。

界面里内嵌了代码编辑器，不用来回切换窗口。它能解释一段陌生代码、 写单元测试、做代码审查、跨语言重构，改完直接在编辑器里看高亮结果。

编辑器支持语法高亮、搜索替换与括号匹配。修改内容以差异形式呈现， 你可以逐处确认后再落地。

适合先把骨架搭出来，再由人去补细节。我们的定位是"帮你从零到八十分"， 最后那二十分的审美判断仍然交给人。

在双手忙着的时候尤其有用——比如在机房排查问题、或者在厨房里 突然想到一个需要记下来的想法。

03

界面

当前预览版的实际界面，未做修饰。

界面刻意做得朴素。没有花哨的欢迎动画，没有侧边栏里塞满图标， 打开就是一个输入框——因为绝大多数时候，你要做的只是说一句话。

  • 01左侧栏：会话列表与工作区切换
  • 02主区域：消息流，代码块带语法高亮
  • 03底部：输入框、语音按钮、思考程度入口
  • 04深色 / 浅色两套配色，跟随系统与手动切换
04

思考程度

五档可调。快和深，由你决定，而不是产品替你决定。

试一下

点一下切换

不是每个问题都值得深度推理。问"今天周几"却让模型推理三十秒， 那是浪费；反过来，重构一个模块时它草草作答，那就是添乱。 所以思考深度被做成一个明确的开关，而不是藏在设置深处的参数。

档位典型耗时适用任务
关闭几乎无延迟闲聊、简单查询、格式转换
低略长于直答短问答、小幅代码修改
中数秒默认档位，覆盖大多数真实工作
高十几秒架构设计、疑难排查、方案比较
最大更久复杂重构、长链条任务

面板里除了思考档位，还能切换当前使用的模型。模型与思考档位是 两个独立的维度：同一个模型可以用不同深度思考，同一档深度也可以 换不同模型来跑。

06

使用场景

几个我们自己在用的例子，比功能列表更能说明问题。

  1. 01

    整理乱掉的下载目录

    两百多个文件名混乱的 PDF、安装包和截图。让它按类型与日期归档到子目录，顺手把明显重复的旧版本挑出来。人做要半小时，它做只要一句话，而且会先把方案列给你看。

  2. 02

    从零搭一个项目骨架

    说清楚要做什么，它建目录、装依赖、写配置、跑通第一次构建。遇到报错自己读日志修，修不动会把原始输出贴给你，而不是编一个看起来合理的解释。

  3. 03

    给明天的课做演示文稿

    把大纲丢进去，十分钟拿到一份结构完整、可直接打开的 .pptx，剩下的时间用来改措辞和配图，而不是纠结第一页该写什么。

  4. 04

    读懂别人的代码

    接手一个没有文档的仓库时，让它逐文件讲清楚数据流向，不确定的地方标注"这里没看懂"而不是强行解释。这是我们对它的一条硬性要求。

  5. 05

    双手忙的时候

    在机房、在路上、在做饭，按住说话就能问，回答直接读出来。语音链路在本地，不用担心说话内容被送去哪家云服务器。

08

常见问题

预览阶段被问得最多的几个。

现在能下载吗？

不能。预览版尚未开放下载，也没有确定发布日期。两个平台都会做：macOS（Apple Silicon）与 Windows（x64）。

需要自己准备 API Key 吗？

使用云端模型时需要，Key 由你自己填写并保存在本机，我们不代管、不上传。如果只想离线使用，可以走内置的 WebLLM 本地推理通道，代价是速度慢一些、能力弱一些。

它会偷偷改我的文件吗？

不会。所有写入都限定在你指定的工作区内，每次操作都会在对话里留下记录。它不会在你没打开应用时做任何事，关闭窗口后不会有任何后台动作。

和普通聊天机器人有什么本质区别？

聊天机器人输出文字，巨天 Agent 输出结果。前者告诉你"可以运行这条命令"，后者直接把命令跑完并把输出拿给你看。这也是为什么我们对权限边界格外谨慎。

为什么叫"巨天 Agent"而不是别的名字？

巨天是工作室的名字，产品沿用前缀保持一致。命名没有更复杂的含义，也不打算起一个需要解释的英文名。

会开源吗？

目前不计划开源客户端代码。工作室已发布的其他项目都是开源的，这个产品因为涉及本地系统权限与模型接入，暂不公开源码。发布后会有完整的使用文档。

支持中文吗？

支持，界面与对话都是中文优先。语音识别与合成也以中文为主。

怎么第一时间知道发布？

关注 GitHub 账号，发布消息会同步到巨天工作室官网与这一页。我们不做邮件订阅，也不做推送。
