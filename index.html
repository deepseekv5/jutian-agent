FEATURES · 02

一句话，它来干活

不只是聊天。巨天 Agent 长了手——能直接在你的电脑上把事情做完。

操作终端

直接在你的电脑上执行命令，实时回显输出。装环境、跑脚本、查日志，说一句就行。

管理文件

读写、整理、检索本地文件。像有个助理坐在旁边，帮你把乱糟糟的目录理顺。

编写代码

内置专业代码编辑器。解释代码、写测试、代码审查、多语言重构，全程在对话里完成。

生成 PPT

一句话大纲，直接产出整套演示文稿。版式、配图、结构，它都想好了。

分析文档

把长文档丢给它：总结、提炼要点、交叉问答。读不完的报告，交给它读完。

语音对话

内置语音识别与语音合成，说话就行，它听得懂也说得出。解放双手的场景尤其好用。

THINKING · 03

五档思考程度
快和深，你来定

不是每个问题都值得深度推理。拖动滑杆，实时切换智能体的思考深度： 琐事秒回，难题让它想透再答。

  • 关闭直接回答，零等待，适合闲聊和简单查询。
  • 低稍作斟酌，快与准之间的平衡点。
  • 中适度思考后作答，日常任务的默认档位。
  • 高深入推理，适合代码架构、方案设计。
  • 最大竭尽全力，复杂问题的压舱底。

ARCHITECTURE · 04

本地优先的架构

数据留在你自己的电脑里，这是设计前提，不是口号。

桌面原生

基于 Electron 构建，macOS 与 Windows 原生安装包，开机即用，不依赖浏览器标签页。

本地记忆

对话与工作区数据存于本地 SQLite，跨会话记住项目上下文，断网也能翻历史。

模型自由

支持接入多种大模型 API，并内置 WebLLM 本地推理通道——敏感任务可以完全不出本机。

语音链路

语音识别与语音合成完整内建，按住说话、听它回答，全程无需第三方客户端。
